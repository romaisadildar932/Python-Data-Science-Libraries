# Introduction to NumPy

## What is NumPy?

NumPy stands for **Numerical Python**. It is a popular Python library used for numerical and mathematical operations.

It provides support for working with large amounts of numerical data efficiently.

NumPy is widely used in:
- Machine Learning
- Deep Learning
- Data Science
- Scientific Computing
- Computer Vision

## Why Do We Use NumPy?

Python lists can store data, but performing mathematical operations on large datasets using lists can be slow.

NumPy provides arrays that make numerical calculations faster and more efficient.

## What is a NumPy Array?

A NumPy array is a collection of elements, usually of the same data type, stored in an organized structure.

Example:

import numpy as np
numbers = np.array([10, 20, 30, 40])
print(numbers)


Output:
[10 20 30 40]


## Installing NumPy

Install NumPy using pip:
pip install numpy


## Importing NumPy

The standard way to import NumPy is:
import numpy as np


Here, `np` is a commonly used short name (alias) for NumPy.

## Important NumPy Features

- Multidimensional arrays
- Fast mathematical operations
- Array indexing and slicing
- Reshaping arrays
- Statistical operations
- Broadcasting

## Python List vs NumPy Array

Python List:
numbers = [1, 2, 3, 4]


NumPy Array:
import numpy as np
numbers = np.array([1, 2, 3, 4])


NumPy arrays are designed for efficient numerical computations.

## Conclusion

NumPy is one of the most important libraries in Python for AI, Machine Learning and Data Science. It provides the foundation for working with numerical data and arrays.
